# RRH Boost FPS V1.3

Resource pack FPS boost untuk Minecraft Bedrock dengan meminimalkan efek partikel dan movement yang tidak perlu.

**[Created by Uther Altara]**

## Fitur Utama
- **0 Partikel Blok & Ledakan:** Menghapus partikel pecahan blok saat ditambang, asap, ledakan (TNT, Creeper, End Crystal, Respawn Anchor), serta partikel hantaman Mace.
- **Wind Charge Ring Minimalis:** Menampilkan cincin shockwave tipis berukuran kecil saat Wind Charge meledak.
- **Indikator Persentase Blok:** Menampilkan persentase retakan blok (`10%` – `100%`) secara jelas tanpa tertutup partikel.
- **Custom Smoked Charcoal UI:** Tampilan Inventory, Container, dan Hotbar transparan dengan aksen silver.
- **4 Pilihan Level Subpack:**
  1. **Level 1 (Lite):** UI Transparan + 0 Partikel Blok/Ledakan/Mace + Wind Charge Ring + Persentase Blok.
  2. **Level 2 (PvP Clean):** Menambahkan Ultra-Low Fire, 0 partikel potion/api, dan ikon efek status transparan.
  3. **Level 3 (Max FPS):** Menambahkan kabut dekat (fog) dan orb XP tak terlihat (Item Drop tetap ON).
  4. **Level 4 (Ultra FPS):** Mengaktifkan seluruh optimasi di atas ditambah Item Drop 2D OFF.

## Cara Pemasangan
1. Unduh file `RRH_Boost_FPS_V1.3.mcpack` pada halaman **Releases**.
2. Buka/ketuk file tersebut untuk mengimpornya otomatis ke Minecraft Bedrock.
3. Aktifkan melalui **Settings > Global Resources** (atau pada pengaturan Resource Pack di World Anda), lalu atur tingkat subpack sesuai kebutuhan.
